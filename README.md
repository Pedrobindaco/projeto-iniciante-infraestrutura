# Arquivo do Vasco

Um pequeno site com informações sobre o Gigante da Colina, contando o contexto histórico, parte do elenco atual, formulário para adição de novos jogadores, informações sobre o estádio e sobre os troféus.

## Como rodar
Abra o arquivo `index.html` no navegador (ou use a extensão Live Server do VS Code).

## Elementos dinâmicos
1. Botão para abrir o menu de navegação
2. Botão para remover jogadores adicionados
3. Botão para expandir o acordeão do respectivo troféu

## Aprendizados
A parte mais difícil foi organizar tudo de maneira coesa na tela e registrar muitos jogadores para o elenco (tanto que nem fiz todo).
Aprendi muito sobre a estrutura dos sites e sobre a importância de dimensionar de acordo com o dispositivo, principalmente o "flex-direction: column" para melhor visualização em dispositivos móveis.
